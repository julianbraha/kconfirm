# Findings

This directory contains some results from running kconfirm.

[kconfirm_smt.md](/findings/kconfirm_smt.md) contains two lists of Linux patches:
1. fixes to Kconfig usage found by using kconfirm-smt,
2. fixes to the Kconfig language and interpreter from the development of kconfirm-smt.

[kconfirm.md](/findings/kconfirm.md) contains a list of Linux patches from using kconfirm (the original, lint-style checker). 

[dead_links_7_0_rc6.txt](/findings/dead_links_7_0_rc6.txt) contains 86 hand-checked known dead links in linux 7.0-rc6
